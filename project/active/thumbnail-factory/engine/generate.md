# 우측 비주얼 생성 규칙 (motif HTML/SVG)

입력: 행의 `비주얼 느낌`(C), `참고 이미지 URL`(E, 선택).
출력: `template.html`의 `.motif`(760×760, 우측, `right:-70px`) 안에 들어갈 **HTML/SVG 조각만**. `<div class="motif">`는 쓰지 말 것 (이미 존재).

## 절대 규칙 (반드시 준수)
- **손으로 사물을 대충 그리지 말 것 (가장 중요)**: 실제 제품(화장품 등)·인물/캐릭터·로봇 같은 건 freehand SVG로 그리면 반드시 조잡해진다 → 그리지 말 것. **이모지도 금지**(이 렌더 엔진에서 국기는 'KR/US' 글자로 깨지고 컬러 이모지도 안 나옴).
  - 대신 **개념·데이터·UI 메타포로 표현**: 글래스 패널/목업, 차트·그래프, 노드·플로우 연결선, 진행 링, KPI 카드 등. 좋은 예 = AI Agent 콘솔 / 수출 $1B 차트 / ChatGPT 광고 목업. 대상은 **텍스트 라벨**(예: `미국`/`중국`/`동남아`) 칩으로.
  - **예외 — 지도/국가 모양은 실제 path로 OK**: 지도가 필요하면 **mapsicon의 정확한 실루엣 path를 받아서** 쓴다(freehand 금지). 예: `curl -sL https://raw.githubusercontent.com/djaiss/mapsicon/master/all/<ISO2소문자>/vector.svg`(한국=`kr`) → `<g>` 추출 → `fill="url(#grad)"`로 그라데이션 칠 → motif에 삽입. (정확 path면 알아보고 고급스러움.)
- **요청하지 않은 텍스트 금지**: 우측 비주얼에 사용자가 주지 않은 문구·라벨·카피·숫자를 **임의로 만들어 넣지 말 것**. 단 주제상 자명한 대상 라벨(수출국명 등)·핵심 수치는 입력(A/B/C)에 근거하면 허용.
- **한글 줄바꿈**: 단어를 중간에서 자르지 말 것. 조사(의·가·을·를·은·는·이·도·로·와·과 등)나 한 글자가 줄 첫머리에 외톨이로 오면 안 됨 → 그 글자를 **앞 줄로 올려서** 끊는다. 예) `AX (AI Transformation)` / `의 격전지가 되다` (X) → `AX (AI Transformation)의` / `격전지가 되다` (O). 의미 단위로 자연스럽게.

## 프리미엄 비주얼 가이드 (이 톤으로 통일 — 중요)
목표: "$150k 에이전시" 급. 평면 단조 도형·손그림 캐릭터(특히 로봇)는 SVG로 조잡해 보이니 금지. 대신 **세련된 글래스 UI + 그라데이션 + 입체감**.

- **컬러는 CSS 변수/팔레트만**: `--purple #6a4dff`, `--blue #005bf0`, `--blue-bright #1b76f5`, `--green #00b37a`(+밝은 `#9b86ff`, `#16d39a`, `#3f86ff`), `--surface #16171C`, `--border #2A2C33`.
- **베이스 항상 포함**: 동심원 링 3개(`.ring .r2 .r3`) + 중앙 글로우(`.glow`).
- **주인공 = 글래스 패널/목업**: `linear-gradient(165deg,#23252e,#15161b 60%,#101116)` 배경 + 1px 보더 + 큰 소프트 섀도(`0 50px 100px -28px rgba(0,0,0,.72)`) + 안쪽 상단 하이라이트(`inset 0 1px 0 rgba(255,255,255,.06)`) + 라운드 24~26px. 폭 ~430~520px.
- **앰비언트 글로우(은은하게)**: 패널 뒤 큰 원형 radial 그라데이션(보라→파랑→초록), **blur 44~52px, 투명도 .2~.26**. 뭉툭한 블롭 금지 — 부드럽게 퍼지게.
- **리치 액센트 2~4개로 채우기**(허전/조잡 방지): ① 떠 있는 미니 카드(스파크라인·미니차트) ② 빛나는 노드(점 + `box-shadow` 글로우) ③ 점선 연결선(데이터 흐름) ④ 진행 링(부분 원, 그라데이션 stroke). → "데이터/자동화/agent" 느낌.
- **입체감**: 그라데이션·다층 섀도. 차트는 살짝 perspective(rotateX/rotateY) 기울여도 좋음.
- **구도**: motif 영역을 넉넉히 채우고 균형 있게(너무 작거나 오른쪽 끝에 쏠리지 않게). 주인공은 `left:43~50%`로 약간 좌측~중앙.
- 텍스트는 실제 노드로(이미지로 굽지 말 것), 폰트 상속(Pretendard). 커스텀 클래스는 충돌 방지 위해 고유 접두사(`ag-`, `m-` 등).

## 참고 이미지가 있을 때
- URL 내용을 해석해 같은 톤의 **HTML/SVG 목업으로 재현**(직접 임베드 X — 스타일 안 맞음). 예: ChatGPT 광고 스크린샷 → 다크 채팅 UI + 스폰서 카드를 코드로 재현.

## 예시 (v1: 대화형 커머스)
```html
<div class="ring"></div><div class="ring r2"></div><div class="ring r3"></div>
<div class="glow"></div>
<div class="pill p1"><span class="dot"></span>AI 추천</div>
<div class="pill p2"><span class="dot"></span>대화형 커머스</div>
<div class="chat"><span class="who">소비자</span>“이거 추천해줘”
  <svg class="spark" viewBox="0 0 24 24" fill="currentColor"><path d="M12 2l1.8 5.2L19 9l-5.2 1.8L12 16l-1.8-5.2L5 9l5.2-1.8z"/></svg>
</div>
```

## 타이틀/강조/서브 처리
- `메인 타이틀`(A): `<h1>` 안에 들어감. `강조 단어`(D)에 해당하는 부분을 `<span class="grad">…</span>`로 감싼다. D가 비면 핵심 키워드 1개를 직접 선택.
- 줄바꿈은 `<br>`로. 2줄 권장(긴 제목은 3줄). **한 줄 길이 가드레일**: copy 영역 폭 880px / h1 70px 기준 한 줄이 넘치면 마지막 글자가 다음 줄로 흘러내린다(고아 글자). 한글 약 14자, 영문 혼용 시 더 짧게 잡아 `<br>`로 끊을 것. 단어 중간이 깨지지 않도록 의미 단위로 끊는다.
- `서브 문구`(B): `.sub` 안에. 앞부분 강조는 `<span class="pt">…</span>`.

## 품질 체크리스트 (매 생성 후 self-check — 반복 실수 방지)
렌더된 PNG를 보고 아래를 반드시 확인. 하나라도 걸리면 고쳐서 다시 렌더한 뒤 제출.
1. **잘림/우측 쏠림 없음**: 우측 요소(라벨·칩·노드·카드)가 화면 밖으로 잘리거나 가장자리에 붙지 않는다. 템플릿이 우측 40px 여백을 강제하지만(scale origin=right), **motif 요소에 음수 right/left 오프셋(`right:-Npx`)을 쓰지 말 것** — 삐져나간다. 비주얼은 motif 좌측~중앙(로컬 x ~330~380 중심)에 둔다. *(가장 자주 난 실수)*
2. **주제를 가리지 않음**: 강조 대상(지도·핵심 요소)을 링/선/박스로 덮지 않는다. 강조는 글로우/색으로.
3. **요청 안 한 텍스트 없음**: 임의 라벨·글자(예: 대상에 이름표 붙이기)를 넣지 않는다. (지도엔 "한국" 같은 글자 X)
4. **허전하지 않음**: 빈 공간은 궤도선·노드·연결선·반짝이·앰비언트 글로우로 채워 균형.
5. **조잡한 freehand 없음**: 실물(지도 제외)을 손으로 그리지 않았다. 지도는 실제 path 사용.
6. **프리미엄 톤**: 글래스 패널·그라데이션·다층 섀도·은은한 글로우 유지. 평면 단조 도형 금지.
